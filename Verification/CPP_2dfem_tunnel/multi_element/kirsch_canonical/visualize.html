Problem description

Plane-strain excavation of a circular tunnel (radius a) in a linearly elastic infinite medium with far-field isotropic stress p. Analytical solution (Kirsch, 1898): ur(r) = p·a² / (2G·r). Compare FEM radial displacement at the tunnel wall against this closed-form result.

Analytical comparison — Kirsch solution

Plane-strain Kirsch wall displacement (compression+, inward+): ur(a, θ) = a / (4G) · [ 2(1−ν)·(σh+σv) + (3−4ν)·(σh−σv)·cos2θ ], with σh = K₀·σv, G = E / (2(1+ν)). Set the tunnel centre (cx, cy) and radius a to match your mesh; K₀ = 1 reduces to ur(a) = p·a·(1−ν)/G.
