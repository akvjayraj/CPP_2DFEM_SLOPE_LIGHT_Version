# Verification Suite Layout

The verification fixtures are now grouped by problem type so that the dashboard,
the GUI Verification tab, and the regeneration scripts all stay legible as the
suite grows.

## Top-level folders

| Folder              | Purpose                                                                                              |
|---------------------|------------------------------------------------------------------------------------------------------|
| `multi_element/`    | True boundary-value problems with full meshes (tunnels, slopes, thick cylinders, footings).         |
| `single_element/`   | Patch-test fixtures: a single T3/T6/Q4/Q8 element under prescribed tractions for code verification. |
| `_index.md` / `.csv`| Master dashboard auto-generated by `tools/run_all_verifications.ps1`.                               |

The dashboard `Suite` column reports each suite as `<category>/<suite>`, e.g.
`multi_element/kirsch_canonical` or `single_element/twin_tunnel`. The GUI's
`VerificationSuiteIndexLoader` resolves either the categorized or the legacy
depth-2 layout, so older checkouts still load cleanly.

## `single_element/` -- patch tests

against the closed-form expectations encoded in each `.dat` header
(`expected_sxx_kPa`, `expected_radial_*`, `expected_pm_*`, `expected_fem_delta_*`).

## Regenerating

All orchestrators have been updated to write into the categorized layout:

```powershell
powershell -ExecutionPolicy Bypass -File tools\run_all_verifications.ps1
powershell -ExecutionPolicy Bypass -File tools\build_tunnel_benchmark_packages.ps1
powershell -ExecutionPolicy Bypass -File tools\build_all_mc_tunnel_smoke_packages.ps1
powershell -ExecutionPolicy Bypass -File tools\build_all_nafems_smoke_packages.ps1
powershell -ExecutionPolicy Bypass -File tools\build_all_geotech_smoke_packages.ps1
powershell -ExecutionPolicy Bypass -File tools\build_all_kirsch_smoke_packages.ps1
powershell -ExecutionPolicy Bypass -File tools\build_all_salencon_smoke_packages.ps1
powershell -ExecutionPolicy Bypass -File tools\build_all_slope_smoke_packages.ps1
```

The master `tools\run_all_verifications.ps1` walks both depth-2 (legacy) and
depth-3 (categorized) layouts so it can run in any order.
