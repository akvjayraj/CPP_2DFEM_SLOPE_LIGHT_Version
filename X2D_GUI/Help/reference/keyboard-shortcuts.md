# Keyboard shortcuts

Shortcuts depend on focus being in the main window. Menu items show their gestures where applicable.

## File and edit

| Shortcut | Action |
|----------|--------|
| Ctrl+N | New project |
| Ctrl+O | Open project |
| Ctrl+S | Save |
| Ctrl+Shift+S | Save As |
| Ctrl+F4 | Close project |
| Ctrl+Z | Undo |
| Ctrl+Y / Ctrl+Shift+Z | Redo |
| Ctrl+P | Print |
| Ctrl+Shift+P | Print preview |
| Ctrl+Shift+G | Import geometry (CSV / DXF / LandXML / GeoJSON) |
| Ctrl+1 … Ctrl+9 | Open recent project by index |
| Delete | Delete selection |

## View and canvas

| Shortcut | Action |
|----------|--------|
| Ctrl+= / Ctrl+NumPad+ | Zoom in |
| Ctrl+- / Ctrl+NumPad- | Zoom out |
| Ctrl+0 / Ctrl+NumPad0 | Zoom to fit |
| Ctrl+Shift+H | Reset zoom |
| P | Toggle pan mode |
| Escape | Exit pan mode |
| F7 | Toggle grid |
| F8 | Toggle model health panel |
| F10 | Toggle axes |

## Help and analysis

| Shortcut | Action |
|----------|--------|
| F1 | Context help for the active main tab |
| Help → User Manual… | Open the manual at the welcome page |

> **Note:** **F5** runs FE Analysis from the Analysis menu. Check the menu for the current gesture if one is shown.
