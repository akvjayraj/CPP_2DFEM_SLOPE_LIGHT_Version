# FE results

Finite-element and strength-reduction runs are launched from the **Script Editor**. Contour and force–displacement plotting that used to live on a separate Results Visualization tab has been removed from the main tab strip.

> **Note:** Stub page. Export of FE results (CSV / VTK) remains available from the **Results** menu when a run snapshot is present.

## Workflow

1. Complete an FE or SRF run from the Script Editor or FE analysis commands.
2. Review solver text output in the Script Editor.
3. Optionally use **Results → Export Results (CSV / VTK)...** for external plotting.

LEM slip-surface results live under the **Postprocessor** tab — see [Postprocessor](../results/postprocessor.md).
