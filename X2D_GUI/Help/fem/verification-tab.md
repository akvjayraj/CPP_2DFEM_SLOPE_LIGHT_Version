# Verification tab

The **Verification** tab runs selected finite-element benchmarks against analytical or published targets (for example NAFEMS patch problems and packaged slope SRF cases under `Verification/slope/` in the repository).

> **Note:** Use the tab’s own problem list and tolerance fields for the current suite.

## When to use it

- Confirm that the installed solver build matches expected patch results
- Compare your local machine’s FE answers to the packaged targets
